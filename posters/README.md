# Arsip poster konten

Folder ini menyimpan poster yang sudah dipublikasikan ke kanal sosial.
File di sini **tidak direferensikan** oleh halaman situs dan tidak memengaruhi
GitHub Pages. Jangan hapus atau ganti nama file yang sudah dipublikasikan —
URL poster bisa masih dipakai di arsip eksternal.

Aturan nama yang dipakai:

- `cc-HHMM.png` — poster reguler, waktu JST.
- `cc-HHMM-<topik>.png` — varian dengan topik.
- `YYYY-MM-DD-HHMM.png` — arsip tanggal lama.
